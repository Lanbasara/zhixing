# 推理与约束

用于研究、建模、设计和审查中，从不完整信息形成可解释的选择。

## 结论的强度与证据相称

区分直接观察、资料陈述、推断和暂时假设。区别的价值是让人知道结论如何
成立、能用到哪里，而不是给每句话增加标签。无法确认的内容可以用于探索，
但不能在传递和摘要中逐渐变成已验证事实。

好的判断不仅指出支持理由，也识别会改变选择的条件。调查深度取决于未知信息
对决定的影响：关键前提值得追查，不影响当前选择的细节可以保留为未知。
信息完整和预测确定都不是行动的普遍前提。

当证据冲突时，考虑来源、观察范围、版本和环境能否解释差异。若仍不能解决，
保留冲突对结论的实际影响，不用平均措辞掩盖它，也不把全部判断一并撤回。

## 模型是为问题服务的简化

模型选择哪些关系值得保留，并让推理能够被检查。它应足以解释当前决策，
不必穷尽现实。图、公式、状态机和文字各有用途；形式的复杂度不能代替解释力。

模型的边界与假设决定其可用范围。遇到反例时，应判断是事实有误、假设失效，
还是模型缺少关键关系。能改变判断的反例比只重复已知结果的例子更有价值。
根据新证据修正模型，是正常的认知进展。

## 让结构承担可判定的约束

能够稳定、明确地判定的要求，适合由类型、接口、数据结构、测试或自动检查
承接。这样可以减少依赖记忆与反复提醒，并让违反约束更早显现。

结构只能保证它实际表达的性质。检查通过不等于目标达成，格式齐全不等于
论证成立，类型正确不等于行为符合用户需要。需要权衡和解释的判断仍应由
承担责任的人或 agent 给出理由，不能借评分、字段或检查表隐藏。

形式约束应放在能可靠执行它、也有能力维护它的层次。若一个要求无法清楚
判定，先澄清它要保护的价值；不要仓促把含糊判断编码成僵硬的门槛。
