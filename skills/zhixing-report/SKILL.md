# 以 HTML 交付有依据的报告

理解报告服务的读者与问题，使用已有研究、任务记录和证据组织成果。
先呈现有依据的主要结论，再展开理由、关键材料与适用范围；结构随内容选择，
不以固定栏目要求反向制造研究工作。

保留来源的时点、版本、条件和判断强度。实测结果、计划、估计和未验证部分
应能区分，图表口径与正文相符。材料之间存在重要冲突时说明或请求相应能力
解决，不能通过润色或汇总把分歧抹去。

依据[HTML 成果约定](../../references/html.md)实现。导航、对照表和交互应
帮助读者查阅证据或比较选择，避免装饰掩盖内容。报告可以包含必要摘要，
权威来源仍可追查，不另行维护项目规则与任务状态。

实际打开并检查主要阅读路径、来源链接和所用交互。交付 HTML 与简短说明，
让读者知道结论覆盖什么、证据在哪里，以及哪些事项仍需判断。报告完成不
代表其记述的方案已经实施或全部得到验证。
