# 让方案容易理解

根据读者已有认识与当前问题，确定最需要解释的关系。材料已经足够时直接
展开；关键事实缺失才补查，不重新启动整个研究或项目恢复过程。

先给出读者需要掌握的模型，再用运行路径、具体例子、图或交互解释因果。
选择能减少理解负担的形式；模拟参数只表达已明确的关系，不能暗示未经证明
的定量结论。复杂性可以渐进展开，核心结论仍应直接读懂。

遵循[HTML 成果约定](../../references/html.md)，保留原方案的重要条件、
替代选择和未知。解释现状、提议或模拟时清楚区分；比喻帮助理解，但应能
回到实际对象和边界。

交付可打开的 HTML，实际检查关键阅读路径及交互。是否完成取决于读者能否
理解本次要说明的问题，不取决于页面数量、动画或图表数量。解释中发现需要
改变方案的实质问题时指出它，不在表达过程中悄悄改写已有决定。
